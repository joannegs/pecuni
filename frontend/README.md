# Pecuni — Frontend

Angular 20, fully standalone,feature-based folder.

## Structure

```
src/app
├── core/
├── shared/
├── features/
├── app.ts / app.html / app.css
├── app.config.ts
└── app.routes.ts
```

## Running locally

```bash
npm install
npm start
```

Requires the backend running on `http://localhost:8080` or the root `docker-compose.yml` once it exists.
